## Decisions to append to 05 (source: Session recommendation under owner delegation, 2026-11-17)

| ID | Decision |
|---|---|
| D300 | Slice 20 scope: admin API + dashboard for banners, pages, FAQs, broadcast campaigns, cities (+ read-only coverage counts), app settings, policy versions, document types. Not built: event types (S16), districts, provider-app banners, campaign deep links. |
| D301 | Banners/pages/FAQs visibility = `is_active`; created hidden; showing needs Arabic and English (`409 TRANSLATION_MISSING`); hiding needs a reason; a visible row cannot lose a language (422); nothing deleted; every write audit-logged. |
| D302 | Pages are per app (client / provider), slug `^[a-z0-9]+(-[a-z0-9]+)*$` ≤ 50 unique per app, changeable only while hidden. |
| D303 | FAQs per app with integer `sort` (omitted → last). |
| D304 | Banners: client app only; required image = own unattached `banner` upload (`uploads.banner` limits); optional destination provider / provider_service / category / service (must exist), city, window; showing also needs an image and a window that has not ended. |
| D305 | Broadcast campaigns: draft → scheduled → sending → sent, draft/scheduled → cancelled (reason); audience = app + optional city (clients by `users.city_id`; providers active and covering the city); send now needs the confirmed live count (`409 AUDIENCE_CHANGED`) and ≥ 1 recipient (`409 NO_RECIPIENTS`); schedule = future time, started by `broadcasts:dispatch-due`; row lock on every move. |
| D306 | Delivery via `Notifier` (E40 `broadcast`, target `broadcast`, dedupe `broadcast:{id}`); row always stored, push gated by `promotions` (D135); no deep link in the MVP. |
| D307 | App-settings editor: `SettingCatalog` lists every key the platform reads; list = catalogue ∪ stored rows; `null` = not configured; values validated by kind (integer, decimal, money string, boolean, integer list, upload limits, json); `null` allowed with a reason; `otp.length` (D3) and `offers.validity_days` (D5) read-only. |
| D308 | Cities: create / rename / sort / stop (reason) / activate; stopping hides the city from pickers and coverage editing only; impact counts (providers covering, clients, open requests). |
| D309 | Document types: create / edit / stop / activate / impact; changes apply to the next upload or submit; uploaded documents unchanged. |
| D310 | Policy versions append-only: next version number under a lock, `effective_from` ≥ now, optional content {ar,en}, flat `values`, reason; no edit, no delete. |
| D311 | Permissions: `content.manage`, `notifications.broadcast`, `settings.manage`; no new permission, no seeder change. |
| D312 | New error codes `TRANSLATION_MISSING`, `AUDIENCE_CHANGED`, `NO_RECIPIENTS` (409). |
| D313 | Flutter: no change (client home banners and FAQs/pages already read the API; broadcast notifications render server text). |
| D314 | Event types stay with Slice 16 (D183). |
