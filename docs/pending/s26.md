# S26 — live data on every app screen (register text)

Source of every decision below: session recommendation under owner delegation, 2026-11-17. Numbered `S26-Dn` so they
do not collide with the D-numbers the parallel sessions (S22–S25) take; the orchestrator renumbers at merge.

## API change (one resource, additive)

`GET provider/profile` (`Provider\Setup\ProfileResource`) now also returns, for her own screens:

| Field | Type | Source |
|---|---|---|
| `city` | `{id, name}` or `null` | `providers.city_id` |
| `started_year` | int or `null` | `providers.started_year` |
| `is_verified` | bool | `providers.is_verified` (admin decision) |

Test: `tests/Feature/Provider/CoverageTest::test_the_profile_shows_her_city_start_year_and_verification`.

## Decisions

- **S26-D1 — Mock data is debug-only.** `MockStore`, `MockAccount`, `MockWalletSource` and `MockPayoutsSource` are
  registered only when `MockMode.enabled` (`kDebugMode`). The prototype preview is `MockMode.preview` = debug and no
  session. Every reader is gated; the string-id routes (`RN-…`, `Q-…`) and the prototype chat open a neutral
  "not available" page in release.
- **S26-D2 — Home sections the API never sends are removed**, not added: `featured_services`, `nearby_providers` and
  `testimonials` (UI, state and widgets deleted). `ShowHomeController` is unchanged.
- **S26-D3 — Dashboard earnings show her lifetime net** (`provider/earnings` → `lifetime.net`); the API keeps no
  monthly series, so the live card has no month bars and no "growth" tag. `409 NOT_CONFIGURED` shows a notice.
- **S26-D4 — Tab badges:** provider new requests = `meta.total` of `provider/service-requests?filter[status]=new`;
  client = `meta.total` of `client/service-requests?filter[status]=offers_received`; unread messages = sum of
  `unread_count` over the newest 50 active conversations (no total endpoint exists).
- **S26-D5 — Provider account stats:** completed bookings (`meta.total` of `provider/bookings` completed), rating
  average and review count. The prototype's "96 % recommend" and "1 h response" are dropped (no API source).
- **S26-D6 — Settings:** the auto-accept switch has no API setting (`quick_offer_enabled` is not exposed), so it shows
  only in the debug preview. The open-requests switch shows her stored `accepts_open_requests`.
- **S26-D7 — Location:** providers have no stored coordinates; `ProviderProfileResource` sends none, and the screen
  shows a "no exact location" state with her coverage instead of a hardcoded Riyadh pin. `banner_url` and `facts`
  were dropped from the app model (never returned).
- **S26-D8 — About page stats removed** (invented figures); the support hero uses the neutral gradient.
- **S26-D9 — `ClientLayoutBloc` kept, wired live:** the audit called it unused, but the client tab bar reads it.
- **S26-D10 — Card tokenizer:** `FakePaymentTokenizer` (D186) is selected through `AppFeatures.fakeCardTokens` only.
