## Roadmap — new Phase 2 row 23 "Store returns" (Status cell)

Completed (2026-11-17) — contract `docs/slice-23-contract.md` (D340–D349, Q200–Q203 answered, E55–E59). Backend: client
returns on delivered orders inside `store.return_window_days` (initial 7, editable), quantities ≤ what is left, reason +
note + up to 3 private photos (`store_return_photo`), `RT-` references, idempotent create, cancel while requested; staff
list / detail / approve / reject (reason) / receive (restock through S18 stock movements) / retry refund; refund of the
lines' paid share (promo discount prorated, shipping never refunded) through Slice 10 `PaymentRefunds`
(`RefundKind::StoreReturn`), settled by the `RefundSettled` listener; `store_return` policy version seeded and public
`shared/store/return-policy`; notifications E55–E59. Dashboard: Store → Returns list + detail. Flutter client: "Request a
return" on a delivered order, "My returns" status list, return detail with cancel. Out: exchanges, store credit, return
labels / carrier pickup, return KPIs and exports (S21 follow-up).
